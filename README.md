# 🍷 Wine Dataset PCA Analysis  

PCA Analysis on Wine Dataset
This Jupyter notebook demonstrates Principal Component Analysis (PCA) applied to the Wine dataset. The code covers:

- Data Loading & Exploration: Loads the dataset and displays samples/statistics.
- Standardization: Scales features for unbiased PCA results.
- PCA Implementation: Computes eigenvalues, eigenvectors, and variance ratios.
- Visualization: Includes variance plots and eigenvector interpretation.
- Key Insights: Explains principal components and their real-world significance.

Usage:
- Run all cells to see PCA steps and visualizations.
- Requires pandas, scikit-learn, and matplotlib.
- Focuses on reducing 13 features to 2-3 principal components while retaining ~80% variance.
